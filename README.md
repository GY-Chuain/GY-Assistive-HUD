# 🎧 GY声道 - 听障玩家的战术HUD

> 🚫 **丑话说在前面：**
> 这玩意儿纯粹是我为了自己打游戏听得清写的，**绝对不碰游戏内存，不改任何游戏数据**。
> 只能用来打单机或者自己做测试！**千万别拿去打竞技网游，更别拿去卖钱**，封号了别怪我没提醒！

## 💡 为啥写这玩意？

因为在平板上打FPS游戏，我听力不太好，老是被不知道哪里冒出来的老六偷背身。
查了查安卓的底层接口，发现可以直接把系统里播放的声音“抽”出来分析。于是干脆自己动手，花时间在CodeAssist里一行行搓出了这个悬浮窗。

它的原理很简单：**听见声音 -> 算左右声道差值 -> 在屏幕上画出来。**

## 🔥 这玩意能干嘛？

- **纯内录，超安全**：用的是安卓官方的 `AudioPlaybackCapture`，就像在你耳朵里装了个监视器，只抓声音不抓画面，根本碰不到游戏内存。
- **只要开枪/开镜就出提示**：右侧直接弹纯正的 `45°` 角度，不挡视野，专治对枪反应慢。
- **高刷屏榨干器**：现在手机动不动就 120Hz、185Hz，这HUD用了底层 `Choreographer` 垂直同步，屏幕多快它多快，丝滑不掉帧。
- **悬浮球随便拖**：单击切室内外，双击直接开/关，不用的时候3秒变半透明，绝不碍眼。
- **不发热、不占内存**：纯代码画图，没有乱七八糟的库，内存占用也就几十兆，打一晚上游戏平板也不烫手。

## 🛠️ 怎么跑起来？

1. 把代码拉下来，丢进 Android Studio（或者直接在平板上用 CodeAssist 打开）。
2. 注意看下 `minSdk` 至少得是 30（Android 11 才能用内录）。
3. 编译打包成 APK 安装。
4. 进去先点“启动系统”给个录屏权限，再去无障碍设置里把服务打开。
